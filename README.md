# Symbiote — мод для Minecraft 1.20.1 (NeoForge)

Мод добавляет:

- **Упавший метеорит** — редкая структура генерации мира (кратер из метеоритной породы
  с светящимся ядром в центре). Появляется примерно 1 раз на 600 чанков
  (`data/symbiote/worldgen/placed_feature/meteorite.json`, `rarity_filter.chance`).
  Внутри кратера рядом с ядром спавнится **дикий (непривязанный) симбиот**, который
  никого не атакует и ждёт носителя.
- **Привязка симбиота к игроку**: подойди к дикому симбиоту из метеорита, зажми
  **Shift** и нажми **ПКМ** — симбиот свяжется с тобой (сущность исчезает, у тебя
  появляется активный бонд, уровень 1). Привязка хранится в capability игрока и
  переживает смерть/перерождение.
- **Система прокачки симбиота**: получай опыт, убивая мобов, пока симбиот привязан
  (`PlayerSymbioteEvents#onLivingDeath`). При наборе нужного опыта — левелап
  (порог = `уровень × 100`), максимум 10 уровней. С каждым уровнем усиливаются
  пассивные бонусы и открываются новые активные способности.
- **10 способностей симбиота** (класс `SymbioteAbility`): от лечения и рывка на
  1-2 уровне до полной формы симбиота на 10-м. Активируются предметом
  **«Воля симбиота»** (`symbiote_core`): ПКМ — использовать текущую выбранную
  способность (с перезарядкой), Shift+ПКМ — переключить способность.
- **Слизь симбиота**, **осколок клинтара** — материалы, крафт брони и щупальца.
- **Броню симбиота** (маска, панцирь, поножи, ботинки) — прочнее алмазной, крафтится из слизи.
  При полном комплекте даёт скорость, прыгучесть, огнестойкость и сопротивление урону,
  пока надета.
- **Щупальце симбиота** (`symbiote_whip`) — меч, который подтягивает врага к игроку при ударе.
- Обычного враждебного моба «Симбиот» (не из метеорита) — прыгает на игрока, роняет слизь.
- Рецепты крафта, лут-таблицу, переводы на русский и английский.

## Способности (уровень открытия → эффект)

| Ур. | Способность | Эффект |
|---|---|---|
| 1 | Regeneration Pulse | Мгновенное лечение, снятие яда/иссушения |
| 2 | Venom Dash | Рывок вперёд |
| 3 | Tendril Grapple | Притягивает ближайшего врага в поле зрения |
| 4 | Web Shot | Снаряд-паутина: замедляет и наносит урон |
| 5 | Camouflage | Невидимость на 10 сек |
| 6 | Venom Strike | Баф перед серией атак |
| 7 | Wall Crawl | Медленное падение / цепкость на 20 сек |
| 8 | Symbiote Roar | Волна отбрасывания + слабость врагам рядом |
| 9 | Adrenaline Surge | Сила III + Стойкость II на 10 сек |
| 10 | Full Symbiote Form | Максимум всех бонусов на 30 сек |

Пассивные бонусы (скорость, прыжок, регенерация, ночное зрение, огнестойкость,
дыхание под водой, стойкость, сила) применяются автоматически каждый тик, пока
симбиот привязан, и масштабируются с уровнем (`PlayerSymbioteEvents#onPlayerTick`).

## Структура

```
src/main/java/com/symbiote/mod/
  SymbioteMod.java              — точка входа
  item/                         — предметы, броня, "Воля симбиота", креатив-вкладка
  entity/                       — сущность симбиота, снаряд Web Shot
  event/                        — бонус полного комплекта брони (базовый мод)
  capability/                   — привязка симбиота, уровень/опыт, все события прокачки
  ability/                      — 10 активных способностей (SymbioteAbility)
  block/                        — блоки метеорита
  worldgen/                     — фича генерации кратера метеорита
  client/                       — рендер модели моба (клиент)
src/main/resources/
  META-INF/mods.toml            — метаданные мода
  assets/symbiote/...           — модели, текстуры, lang-файлы
  data/symbiote/...             — рецепты, лут-таблица, ворлдген (feature/placed_feature)
  data/symbiote/neoforge/biome_modifier/ — добавление метеорита в биомы оверворлда
```

Текстуры (`gen_textures.py`) — простые чёрно-красные плейсхолдеры, сгенерированные
скриптом на Python (Pillow). Замените PNG в `textures/item`, `textures/models/armor`
и `textures/entity` на свои рисунки — размеры и расположение областей сохранены
(16×16 для иконок предметов, 64×32 для слоёв брони, 64×64 для скина моба).

## Как собрать

1. Установите **JDK 17**.
2. Нужен интернет при первой сборке (Gradle скачает NeoForge и generate wrapper).
   Если у вас ещё нет `gradlew`/`gradlew.bat`, сгенерируйте обёртку:
   ```
   gradle wrapper --gradle-version 8.8
   ```
   (либо откройте проект в IntelliJ IDEA — она сама предложит создать wrapper).
3. Соберите мод:
   ```
   ./gradlew build
   ```
   Готовый `.jar` появится в `build/libs/symbiote-1.0.0.jar`.
4. Для локального теста: `./gradlew runClient`.

## Установка

Скопируйте собранный `.jar` из `build/libs/` в папку `mods` клиента/сервера
с установленным **NeoForge 1.20.1** (версия loader'а указана в `gradle.properties`,
`neo_version = 47.1.99` — при необходимости замените на актуальную для 1.20.1).

## Важно про версии API

Мод написан под ветку **NeoForge 1.20.1** (формат `META-INF/mods.toml`,
классический enum-based `ArmorMaterial`, `TickEvent.PlayerTickEvent`).
Если ваша фактическая версия NeoForge из `gradle.properties` подтянет другой
минорный релиз API, могут потребоваться мелкие правки (например, если Gradle
ругается на `ArmorMaterial` или `TickEvent` — значит, в вашей сборке они уже
заменены на более новые аналоги; тогда используйте автодополнение IDE, чтобы
найти актуальные названия классов).
